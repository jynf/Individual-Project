Description:
This HTML program displays a tournament schedule in a grid format from a local JSON file.
User interaction includes a search bar and mouse hovering detection to make information boxes larger for readability.

How to Run:
1-Using a machine with python and windows, open the command prompt in the folder with the files.
2-Enter "py -m http.server 8000" into the terminal to start a local server running the website
3-Open a browser and search "http://localhost:8000" to access the webpage
-Need to host the webpage locally since browsers block the fetch request for the JSON.
